# خطة تنفيذ المميزات الجديدة

المطلوب ضخم جداً (30+ ميزة). هنفذه على **6 مراحل** — كل مرحلة قابلة للاستخدام لوحدها. المميزات الي محتاجة مفاتيح خارجية منك هعلّمها **[محتاج منك]** ونعملها في الآخر.

---

## المرحلة 1: قاعدة البيانات والبنية التحتية
- جدول `cart_items` (سلة مشتريات)
- جدول `coupons` + `coupon_redemptions` (أكواد خصم)
- جدول `favorites` (مفضلة)
- جدول `reviews` (تقييمات)
- جدول `tickets` + `ticket_messages` (دعم فني)
- جدول `notifications` (إشعارات)
- جدول `referrals` + عمود `wallet_balance` في `profiles`
- جدول `audit_log` (سجل نشاط أدمن)
- جدول `product_stock` (مخزون اختياري)
- جدول `blog_posts` (مدونة)
- جدول `faqs`
- توسيع `user_roles` لدعم صلاحيات متعددة (admin/moderator/support)

## المرحلة 2: تجربة المستخدم الأساسية
- **صفحة حسابي** `/account` — تعديل اسم/رقم/إيميل، تغيير باسورد، عرض الرصيد
- **سلة المشتريات** `/cart` — إضافة/حذف، حساب الإجمالي، تطبيق كوبون
- **Checkout جديد للسلة** — دفع أكتر من اشتراك مرة واحدة
- **صفحة المفضلة** `/favorites` + زرار قلب على كل منتج
- **تقييمات ومراجعات** على صفحة المنتج (نجوم + تعليق)

## المرحلة 3: دعم فني وإشعارات
- **نظام تذاكر** `/support` — فتح تذكرة، مراسلات، حالة (open/closed)
- **مركز إشعارات** — جرس في الهيدر، صفحة `/notifications`
- **إشعار قرب انتهاء الاشتراك** — Cron job يومي
- **نظام إحالة** — كود إحالة لكل مستخدم، رصيد عند إتمام صديق أول طلب

## المرحلة 4: محتوى الموقع والصفحات العامة
- `/about` — من نحن
- `/refund-policy` — سياسة الاسترجاع
- `/faq` — أسئلة شائعة (ديناميكية من DB)
- `/blog` + `/blog/$slug` — مدونة
- `/offers` — صفحة عروض مخصصة
- **بانر عروض متحرك** في الأعلى
- **Dark/Light toggle** (الافتراضي Dark)
- **صفحات هبوط SEO** لكل منتج — meta tags ديناميكية + og:image
- **Sitemap.xml** ديناميكي + robots.txt

## المرحلة 5: لوحة إدارة متقدمة
- **إحصائيات** — Dashboard برسوم بيانية (مبيعات، أفضل منتجات، عملاء جدد)
- **إدارة الكوبونات** — إضافة/تعديل/حذف
- **إدارة المخزون** — تعيين عدد لكل منتج
- **إدارة المدونة والـ FAQ**
- **إدارة الأدمن** — إضافة مشرفين بصلاحيات (admin/moderator/support)
- **سجل نشاط** — كل حاجة أدمن يعملها تتسجل
- **تصدير Excel/CSV** للطلبات والعملاء
- **رسائل جماعية** — لكل العملاء عبر إشعارات داخل الموقع (WhatsApp broadcast محتاج API)

## المرحلة 6: التكاملات الخارجية [محتاج منك]
- **Google Analytics** — محتاج GA4 Measurement ID
- **Facebook Pixel** — محتاج Pixel ID
- **WhatsApp Cloud API** — محتاج Meta Business Account + Phone Number ID + Access Token (رد آلي + إرسال بعد الشراء)
- **Email Marketing** — محتاج Resend API key (Welcome + Newsletter)
- **Multi-language عربي/إنجليزي** — هعملها لكن هتاخد وقت طويل، ممكن نأجلها لآخر مرحلة

## ملاحظات مهمة
1. هبدأ فوراً بالمرحلة 1 و2 مع بعض (Migration + كود). كل مرحلة توصل جاهزة قبل ما أبدأ الي بعدها.
2. **الحاجات الي محتاجة مفاتيح خارجية** (Analytics, Pixel, WhatsApp API, Email) — لما نوصلها هطلب منك المفاتيح خطوة بخطوة.
3. الحاجات الي متعملة أصلاً (زي WhatsApp عن طريق `wsend.co`) هتفضل شغالة كما هي.
4. المدة المتوقعة: كل مرحلة ~1-2 دورة رسائل. المجموع ~10-12 دورة.

**موافق نبدأ بالمرحلة 1 و2؟** لو موافق قوللي "يلا" وأنا أنفذ.
